# 🧪 Нагрузочное тестирование (Load Tests & Benchmarks)

Изолированный комплекс стресс-тестирования, бенчмаркинга и сквозной симуляции движка мониторинга **Lighter Monitor** под ограничения **Cloudflare Workers Free Tier** (50ms CPU, 50 subrequests, 20s wall-clock, 100 SQLite variables).

---

## 📁 Структура папки

```text
load-tests/
├── README.md               # Документация и инструкции
├── seed.ts                 # Генератор синтетических данных (50 юзеров, 200 аккаунтов, 500 позиций)
├── seed.sql                # Сгенерированный SQL-дамп для локальной БД D1
├── profile_engine.ts       # Изолированный профайлер подсистем (SQL, Reverse Indexing, In-memory)
└── simulate_cron_tick.ts   # Сквозная симуляция крона с моками сети (задержки, зомби, троттлинг)
```

---

## 🚀 Команды для запуска

Все команды вынесены в `package.json` корневого проекта:

### 1. Перегенерация и накат синтетических данных

```bash
bun run seed
```

Генерирует чистый `load-tests/seed.sql` и накатывает его на локальную SQLite БД (`.wrangler/state/...`).

### 2. Запуск изолированного профайлера подсистем

```bash
bun run profile
```

Замеряет задержки выполнения отдельных фаз:

- Время SQL Round-Robin (`~0.5 ms`);
- Сравнение выборки Full Sweep (`~1.5 ms`) vs SQL Reverse Indexing (`~1.0 ms`) vs Fallback > 50 токенов (`~3.4 ms`);
- In-memory фильтрация и сортировка по срочности (`~2.5 ms`);
- Дедупликация JIT-запросов на китовых кошельках (**> 50% экономии** сетевых вызовов);
- Краевые случаи: микро-цены мемкоинов (`PEPE` $0.00001234), истекшие vs активные режимы Mute.

### 3. Сквозная симуляция работы крона (End-to-End)

```bash
bun run simulate
```

Запускает реальную функцию `runCronMonitor` с перехваченным сетевым слоем:

- Имитирует сетевые задержки биржи (50–100 мс) и Telegram (30 мс);
- Симулирует обнаружение ликвидированных позиций (зомби) и их пакетное удаление из D1;
- Проверяет соблюдение строгой паузы между сообщениями одному пользователю (`>= 850 мс`);
- Контролирует лимиты Cloudflare: общее время (`< 15 с`) и subrequests (`< 45`).
