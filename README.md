# ⚡️ Lighter Monitor Bot

Современный high-performance Telegram-бот для круглосуточного мониторинга открытых позиций, импульсов цен и рисков ликвидации на **Lighter DEX** (**Robinhood Lighter** и **Lighter Mainnet**).

Архитектура построена на стеке **Cloudflare Workers (Edge Serverless) + Cloudflare D1 (SQLite) + grammY + Bun**, строго оптимизирована под лимиты бесплатного тарифа Cloudflare Free и соответствует принципу **Zero-CLI** (100% управление через визуальные кнопки и пошаговые визарды).

---

## 🌟 Ключевые возможности

### 1. Поддержка двух сетей (Multi-Network)

- 🟠 **Robinhood Lighter** (`api.rh.lighter.xyz`)
- ⚡️ **Lighter Mainnet** (`api.lighter.xyz`)
- Единый мониторинг портфеля: можно одновременно отслеживать позиции хеджа (например, Long на RH и Short на Mainnet).

### 2. Импульсный мониторинг цен (Price-Driven Alerting)

- **Устранение проблемы N+1**: бот не спамит биржу запросами по каждому аккаунту. Каждую минуту запрашивается всего 2 глобальных снэпшота цен (`exchangeStats`) — по одному на каждую сеть.
- **In-Memory фильтрация**: позиции проверяются на превышение персонального шага цены (порога алертов) в памяти воркера без сетевых затрат.
- **JIT (Just-In-Time) актуализация**: детальный запрос состояния аккаунта выполняется только тогда, когда цена актива реально сделала импульс (с дедупликацией через intra-cron кэш).
- **Динамический кулдаун (Анти-флаппинг)**:
  - 3 минуты при шаге $\le 0.5\%$
  - 5 минут при шаге $0.5\% - 1.0\%$
  - 8 минут при шаге $> 1.0\%$
  - Мгновенное пробитие кулдауна при резком двойном скачке ($\ge 2 \times \text{порог}$).
- **Детекция закрытия позиций**: автоматическая пакетная очистка ликвидированных или закрытых позиций без лишних запросов к базе.

### 3. Боевые 3-слойные алерты

Алерт спроектирован так, чтобы трейдер с первого взгляда за 1 секунду оценивал обстановку:

1. **Локальный импульс**: текущая цена крупным планом, направление движения (`🟢 В плюс` / `🔴 В просадку`) и дельта от предыдущей засечки.
2. **Глобальное состояние**: сеть, аккаунт/алиас, размер позиции, цена входа и текущий нереализованный PnL.
3. **Запас прочности**: цена ликвидации, расстояние в процентах и цветовой статус риска (`🚨 [КРИТИЧНО]`, `⚠️ [ОПАСНО]`, `⚡️ [ВНИМАНИЕ]`).
4. **Быстрый переход**: инлайн-кнопка прямой ссылки на торговую пару на бирже.

### 4. Zero-CLI интерфейс и визарды

- **Постоянное нижнее меню (Reply Keyboard)**: `📊 Мои сделки`, `💼 Мои кошельки`, `➕ Добавить кошелек`, `⚙️ Настройки`.
- **Пошаговый мастер добавления кошельков**: выбор сети кликом ➔ ввод индекса ➔ автоматическая проверка на бирже с показом адреса и залога ➔ ввод понятного имени (алиаса) или пропуск.
- **Интерактивные карточки аккаунтов**: просмотр позиций, быстрое переименование и удаление в один клик.
- **Настройка шага алертов**: сетка пресетов (`0.3%`, `0.5%`, `0.8%`, `1.0%`, `1.5%`, `2.0%`) + кнопка ввода любого кастомного процента (`0.1%`–`10.0%`).
- **15-минутный TTL визарда**: защита от «застревания» в диалоге при долгом бездействии.
- **Режим «Тихий сон» (Mute)**: возможность отключить алерты на 4 часа прямо из меню настроек.

### 5. Сводка сделок и расчет хеджа (`/positions`)

- Мгновенный вывод из кэша D1 (~40–60 мс).
- Четкие разделители между аккаунтами.
- **Блок ИТОГО**: автоматический расчет суммарного UnPnL по всем счетам и суммарной маржи.
- Кнопка **`🔄 Обновить`** с 15-секундным троттлингом для предотвращения rate limit со стороны биржи.

## 🤖 Команды бота

Хотя ботом можно полностью управлять кнопками, поддерживаются и команды:

| Команда                       | Описание                                                 |
| :---------------------------- | :------------------------------------------------------- |
| `/start`                      | Главное меню, приветствие и включение нижней клавиатуры  |
| `/positions`                  | Открытые сделки, риски ликвидации и суммарный дельта-PnL |
| `/list`                       | Список отслеживаемых аккаунтов и карточки управления     |
| `/settings`                   | Меню настроек шага цены и режима сна                     |
| `/threshold <число>`          | Прямая установка шага цены (например, `/threshold 0.4`)  |
| `/stats` (или `/admin`)       | Системный дашборд и бизнес-метрики (только для админа)   |
| `/add_rh <индекс> [имя]`      | Быстрое добавление кошелька Robinhood Lighter            |
| `/add_mainnet <индекс> [имя]` | Быстрое добавление кошелька Lighter Mainnet              |
| `/remove_rh <индекс>`         | Удаление аккаунта Robinhood Lighter                      |
| `/remove_mainnet <индекс>`    | Удаление аккаунта Lighter Mainnet                        |

## 💻 Локальная разработка

### Требования

- [Bun](https://bun.sh) (v1.2+)
- Cloudflare Wrangler CLI

### 1. Установка зависимостей

```bash
bun install
```

### 2. Инициализация локальной базы D1

```bash
bun run d1:init
```

### 3. Запуск тестов

Проект покрыт 39 модульными тестами (математика маржи/ликвидации, API биржи, форматеры сообщений, логика визардов, reverse-индексация и метрики):

```bash
bun test
```

### 4. Линтинг и форматирование (Oxc Stack)

В проекте используются высокопроизводительные компиляторы нового поколения **Oxlint** и **Oxfmt**:

```bash
# Проверка качества кода линтером
bun run lint

# Авто-исправление линтером
bun run lint:fix

# Форматирование файлов
bun run format

# Проверка форматирования
bun run format:check

# Проверка типов TypeScript
bun run typecheck
```

### 5. Локальный запуск воркера

```bash
bun run dev
```

## 🚀 Развертывание в Cloudflare (Production)

### 1. Создание удаленной базы D1

```bash
bunx wrangler d1 create lighter-db
```

Скопируйте `database_id` в `wrangler.toml`:

```toml
[[d1_databases]]
binding = "DB"
database_name = "lighter-db"
database_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
```

### 2. Накатывание схемы базы данных

```bash
bunx wrangler d1 execute lighter-db --remote --file=./schema.sql
```

### 3. Установка секретов

```bash
# Токен бота от @BotFather
bunx wrangler secret put TELEGRAM_BOT_TOKEN

# Секретный токен для проверки подлинности вебхука
bunx wrangler secret put TELEGRAM_SECRET_TOKEN

# (Опционально) Telegram ID администратора для доступа к /stats и /admin
bunx wrangler secret put ADMIN_TELEGRAM_ID

# (Опционально) URL Heartbeat-мониторинга крона (Healthchecks.io / Better Stack)
bunx wrangler secret put HEALTHCHECK_URL
```

### 4. Деплой

```bash
bun run deploy
```

### 5. Регистрация команд в меню Telegram

Откройте в браузере или вызовите через curl:

```bash
curl "https://<ВАШ_ВОРКЕР>.workers.dev/setup-commands"
```

### 6. Установка вебхука Telegram

```bash
curl -F "url=https://<ВАШ_ВОРКЕР>.workers.dev" \
     -F "secret_token=<ВАШ_TELEGRAM_SECRET_TOKEN>" \
     "https://api.telegram.org/bot<ВАШ_TELEGRAM_BOT_TOKEN>/setWebhook"
```

Проверить статус подключения вебхука:

```bash
curl "https://api.telegram.org/bot<ВАШ_TELEGRAM_BOT_TOKEN>/getWebhookInfo"
```
