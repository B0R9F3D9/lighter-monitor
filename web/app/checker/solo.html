Method B: Zero-Trust Manual F12 Network Export
1 Open Lighter in your browser, press F12 (DevTools), and switch to the Network tab.
2 Filter by trades and select the API response (/trades?account_index=...).
3 Save response as JSON file(s) or copy response. You can drop multiple pagination files or multiple accounts — Checker will stitch them seamlessly.
100% local in-browser processing. Zero scripts run on your wallet.
